# 第一关挑战：大模型推理系统实验
## 实验说明
本作业完成SGLang推理框架相关挑战，目标理解大模型在线推理流程、RadixCache、PagedAttention等缓存优化机制，基于Mooncake FAST'25 trace构造请求负载。

> 环境说明：WSL环境部署SGLang时，受sgl‑kernel底层算子兼容性问题，无法启动真实GPU推理服务，因此使用Ray仿真完成Mooncake trace负载的相关实验。
